# LoomLab

本地纺织材质贴图工作台。新业务代码位于 loomlab；image_lab 和 /prepare 是复用自有 solo_14 的完整源图准备工作台（配准、去噪、曝光、色彩、遮罩等），可下载准备结果再导入材质。没有复用图集打包业务。

## 启动

`docker compose up --build -d`，打开 http://127.0.0.1:18915 。命名卷 solo15-loomlab_loomlab_data 保存材质、版本和源图；`docker compose down` 保留卷，`down -v` 会删除数据。常规 Python 环境运行 `pip install -r requirements.txt` 后 `./start.sh`；PORT 与 LOOMLAB_DATA_DIR 可更改地址及存储。Dockerfile基于本地已有solo12-scanweave:1.0依赖镜像，Python3.11与3.12依赖按requirements标记安装。

## 实际功能

1. 经/纬两色与组织结构生成织纹底色和相对高度，含平纹、斜纹、方平组织。
2. 导入PNG/JPEG照片作为底色源图；EXIF朝向归一、透明像素在线性色彩空间与暗底合成。
3. 源图周期坐标的缩放、平移与旋转，以最近邻采样保持原像素。
4. 相对高度从线性亮度生成，设置高低点、反转和周期平滑。
5. 高度派生单位切线法线，可选Y向上或向下约定。
6. 高度局部细节调制基础粗糙度。
7. 周期邻域高度生成近似环境遮蔽AO。
8. 平面光照预览，可改变光源方位与仰角；线性照明后转sRGB显示。
9. 底色、高度、法线、粗糙、AO分别预览和下载。
10. 3×3重复预览检查材质拼接。
11. 任一通道的边界平均/峰值误差及灰度直方图诊断。
12. ORM打包：R=AO、G=粗糙度、B=非金属0；PNG数据通道不作sRGB变换。
13. 导出贴图ZIP与色彩空间/法线约定清单。
14. 命名材质版本，恢复当时参数与不可变源图。
15. 只读版本对照：当前状态与任意历史版本（或两个历史版本）可分界线拖动、并排、差异图三种方式查看，支持底色/高度/法线/粗糙度/AO 五通道；差异统计给出变化范围（均值、95 分位、最大值、RMS 与有符号均值，法线为方向角度）。
16. 下载/导入可编辑工程，保留版本所引用的各张源图；重新导入后历史版本仍可直接对照。
17. /prepare源图准备工具可对齐、融合、校色、遮罩、接片并导出；它是独立输入准备步骤。

操作：首页创建合成示范，切换各贴图，改变组织/高度/光照后应用，留存版本，再下载贴图和工程。导入自有照片后选择照片模式。示范完全为程序合成，不冒充摄影实测。

## 版本对照的数值约定

对照全程只读，不调用任何写入接口，不改写当前材质、revision 或历史版本；退出对照后继续编辑，工程重新导入（`/loom/import`）后仍可对原来留下的版本做同样对照。

- 输出尺寸不同：按周期纹理坐标做包裹双线性重采样，把两侧对齐到较小边长的同一网格，保证同一材质位置对应，而不是简单缩放拉伸。
- 法线 Y 约定不同（up/down）：在 8-bit 整数编码层面先翻转 G 通道（down 与 up 精确满足 g'=255−g），再解码成单位向量按方向夹角比较；纯粹切换约定的差异仅为量化噪声（均值约 0.01°），不会整图报警。法线比较的是向量方向偏差（角度），不把法线编码颜色差当作表面变化。
- 底色用 RGB 欧氏幅度（热色图）并附各通道均值变化；高度/粗糙度/AO 用有符号差异 B−A（蓝=减少、红=增加，中性灰=无变化），增益按 95 分位自动标定。
- 只读 API：历史视图 `/loom/materials/{id}/view/{view}/map/{channel}.png`（view 为 `current` 或版本 id），差异图与统计 `/loom/materials/{id}/compare/{a}/{b}/map|stats/{channel}`。

## 数值语义和限制

源图不超过4096²；材质输出32至1024²，每次在CPU同步计算，不承诺未测大规模吞吐。高度是归一化相对量，没有测量毫米尺度。AO和高光都是近似，不是物理渲染器。织纹重复数需用户按组织周期选择，首尾不兼容时诊断会显示接缝；程序不会自动修接缝。边界像素差是诊断量，连续采样首尾像素无需完全相等。

正常API以 `/loom/materials` 管理材质，修改请求携带当前revision防止旧页面覆盖；图片`/loom/materials/{id}/map/{channel}.png`，诊断`/inspect/{channel}`，下载`/export.zip`与`/project.zip`，工程导入`POST /loom/import`。原始图片内容寻址并保留，版本恢复不会改写旧图。版本对照为只读 GET 接口（view/compare，见上节），不触发 revision 变化。
