# LoomLab

本地纺织材质贴图工作台。新业务代码位于 loomlab；image_lab 和 /prepare 是复用自有 solo_14 的完整源图准备工作台（配准、去噪、曝光、色彩、遮罩等），可下载准备结果再导入材质。没有复用图集打包业务。

## 启动

`docker compose up --build -d`，打开 http://127.0.0.1:18915 。命名卷 solo15-loomlab_loomlab_data 保存材质、版本和源图；`docker compose down` 保留卷，`down -v` 会删除数据。常规 Python 环境运行 `pip install -r requirements.txt` 后 `./start.sh`；PORT 与 LOOMLAB_DATA_DIR 可更改地址及存储。Dockerfile基于本地已有solo12-scanweave:1.0依赖镜像，Python3.11与3.12依赖按requirements标记安装。

## 实际功能

1. 经/纬配色循环与组织结构生成织纹底色和相对高度，含平纹、斜纹、方平组织与自定义组织。
2. 自定义组织：2至64格的网格编辑器，格值1=经纱在上、0=纬纱在上；支持点击/拖动绘制、整面填充、反相、改尺寸（旧格按取模保留）。
3. 可导入黑白组织图（PNG/JPEG）按当前网格尺寸采样，深色格=经纱在上，方向相反可一键反相后继续修改。
4. 经纱、纬纱各支持1至16色循环配色，编辑对话框内实时预览底色与织纹起伏（可关闭自动保存）。
5. 组织循环与配色循环长度不同时，按各自最小公倍数取共同周期，并把经/纬纱数向上取整到完整周期；平铺预览与贴图输出均为完整周期单元，末根纱不会被截断。
6. 单方向共同周期超过256根纱的组合在界面给出红色限制说明并阻止生成，后端同步校验；网格≤64、配色≤16色。
7. 自定义组织与配色随材质设置保存进工程，版本快照、工程导出/导入完整恢复，贴图包清单包含循环周期元数据。
8. 导入PNG/JPEG照片作为底色源图；EXIF朝向归一、透明像素在线性色彩空间与暗底合成。
9. 源图周期坐标的缩放、平移与旋转，以最近邻采样保持原像素。
10. 相对高度从线性亮度生成，设置高低点、反转和周期平滑。
11. 高度派生单位切线法线，可选Y向上或向下约定。
12. 高度局部细节调制基础粗糙度。
13. 周期邻域高度生成近似环境遮蔽AO。
14. 平面光照预览，可改变光源方位与仰角；线性照明后转sRGB显示。
15. 底色、高度、法线、粗糙、AO分别预览和下载。
16. 3×3重复预览检查材质拼接。
17. 任一通道的边界平均/峰值误差及灰度直方图诊断。
18. ORM打包：R=AO、G=粗糙度、B=非金属0；PNG数据通道不作sRGB变换。
19. 导出贴图ZIP与色彩空间/法线约定/组织周期清单。
20. 命名材质版本，恢复当时参数与不可变源图。
21. 下载/导入可编辑工程，保留版本所引用的各张源图与自定义组织网格。
22. /prepare源图准备工具可对齐、融合、校色、遮罩、接片并导出；它是独立输入准备步骤。

操作：首页创建合成示范，切换各贴图，改变组织/高度/光照后应用，留存版本，再下载贴图和工程。导入自有照片后选择照片模式。示范完全为程序合成，不冒充摄影实测。

## 数值语义和限制

源图不超过4096²；材质输出32至1024²，每次在CPU同步计算，不承诺未测大规模吞吐。高度是归一化相对量，没有测量毫米尺度。AO和高光都是近似，不是物理渲染器。织纹重复数需用户按组织周期选择，首尾不兼容时诊断会显示接缝；程序不会自动修接缝。边界像素差是诊断量，连续采样首尾像素无需完全相等。

自定义组织网格每方向2至64格，经/纬配色循环各1至16色；组织循环与配色循环的共同周期（最小公倍数）单方向不得超过256根纱，超限组合在界面与后端同时拦截。输出纱数按共同周期向上取整，请求值与实际值可在 `GET /loom/materials/{id}/weave-info` 及贴图包清单中核对。

正常API以 `/loom/materials` 管理材质，修改请求携带当前revision防止旧页面覆盖；图片`/loom/materials/{id}/map/{channel}.png`，诊断`/inspect/{channel}`，循环周期`/weave-info`，下载`/export.zip`与`/project.zip`，工程导入`POST /loom/import`。原始图片内容寻址并保留，版本恢复不会改写旧图。
