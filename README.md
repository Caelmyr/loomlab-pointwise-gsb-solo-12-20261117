# LoomLab

本地纺织材质贴图工作台。新业务代码位于 loomlab；image_lab 和 /prepare 是复用自有 solo_14 的完整源图准备工作台（配准、去噪、曝光、色彩、遮罩等），可下载准备结果再导入材质。没有复用图集打包业务。

## 启动

`docker compose up --build -d`，打开 http://127.0.0.1:18915 。命名卷 solo15-loomlab_loomlab_data 保存材质、版本和源图；`docker compose down` 保留卷，`down -v` 会删除数据。常规 Python 环境运行 `pip install -r requirements.txt` 后 `./start.sh`；PORT 与 LOOMLAB_DATA_DIR 可更改地址及存储。Dockerfile基于本地已有solo12-scanweave:1.0依赖镜像，Python3.11与3.12依赖按requirements标记安装。

## 实际功能

1. 经/纬两色与组织结构生成织纹底色和相对高度，含平纹、斜纹、方平组织。
2. 导入PNG/JPEG照片作为底色源图；EXIF朝向归一、透明像素在线性色彩空间与暗底合成。
3. 源图周期坐标的缩放、平移与旋转，以最近邻采样保持原像素。
4. 相对高度从线性亮度生成，设置高低点、反转和周期平滑。
5. 高度派生单位切线法线，可选Y向上或向下约定。
6. 高度局部细节调制基础粗糙度。
7. 周期邻域高度生成近似环境遮蔽AO。
8. 平面光照预览，可改变光源方位与仰角；线性照明后转sRGB显示。
9. 底色、高度、法线、粗糙、AO分别预览和下载。
10. 3×3重复预览检查材质拼接。
11. 任一通道的边界平均/峰值误差及灰度直方图诊断。
12. ORM打包：R=AO、G=粗糙度、B=非金属0；PNG数据通道不作sRGB变换。
13. 导出贴图ZIP与色彩空间/法线约定清单。
14. 命名材质版本，恢复当时参数与不可变源图。
15. 下载/导入可编辑工程，保留版本所引用的各张源图。
16. 浮雕样片：按当前材质高度生成可打印的三维样片，可设实际长宽、底板厚度、最大起伏（毫米）与网格精细程度；预览高度范围、网格形状和顶点预算，导出带底面与侧壁的闭合 OBJ。
17. /prepare源图准备工具可对齐、融合、校色、遮罩、接片并导出；它是独立输入准备步骤。

操作：首页创建合成示范，切换各贴图，改变组织/高度/光照后应用，留存版本，再下载贴图和工程。导入自有照片后选择照片模式。示范完全为程序合成，不冒充摄影实测。

浮雕样片操作：在“浮雕样片”区设定长宽、底板厚度、最大起伏与网格密度，保存后预览高度范围与网格形状，再导样片 OBJ。样片的长宽和厚度是实际毫米尺寸，顶面高度=底板厚度+材质相对高度×最大起伏，因此平面高度也会得到一块正常薄板。超出约25万顶点的提醒预算时页面和导出前都会提示，导出不会静默缩减你选的尺寸或起伏。样片参数保存在材质设置中，工程ZIP与版本恢复都会带回同一组参数，可复现同一块样片；普通贴图包不含样片。

## 数值语义和限制

源图不超过4096²；材质输出32至1024²，每次在CPU同步计算，不承诺未测大规模吞吐。高度是归一化相对量，没有测量毫米尺度。AO和高光都是近似，不是物理渲染器。织纹重复数需用户按组织周期选择，首尾不兼容时诊断会显示接缝；程序不会自动修接缝。边界像素差是诊断量，连续采样首尾像素无需完全相等。浮雕样片的毫米尺度只用于几何输出，材质高度仍是相对量；样片网格96²以上导出需数秒，1024²约百万级面片。

正常API以 `/loom/materials` 管理材质，修改请求携带当前revision防止旧页面覆盖；图片`/loom/materials/{id}/map/{channel}.png`，诊断`/inspect/{channel}`，下载`/export.zip`与`/project.zip`，工程导入`POST /loom/import`。原始图片内容寻址并保留，版本恢复不会改写旧图。

浮雕样片API：`GET /loom/materials/{id}/sample/preview` 返回毫米高度范围、降采样网格形状与顶点预算，可用 width/length/base/relief/mesh 查询参数试算未保存设置；`GET /loom/materials/{id}/sample.obj` 按已保存设置导出闭合OBJ。超过提醒预算时样片导出需带 `confirm=1`，否则返回400并给出顶点数与预估大小，不会改动尺寸。网格16至1024，长宽1至400毫米，底板0.2至30毫米，起伏0.05至30毫米。OBJ顶面、底面与侧壁共享顶点，每条边恰好被两个面共用且方向相反；非平面四边形单元在查看器中可能显示轻微折痕，属于正常渲染拆面。
