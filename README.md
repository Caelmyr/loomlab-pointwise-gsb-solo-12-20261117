# LoomLab

本地纺织材质贴图工作台。新业务代码位于 loomlab；image_lab 和 /prepare 是复用自有 solo_14 的完整源图准备工作台（配准、去噪、曝光、色彩、遮罩等），可下载准备结果再导入材质。没有复用图集打包业务。

## 启动

`docker compose up --build -d`，打开 http://127.0.0.1:18915 。命名卷 solo15-loomlab_loomlab_data 保存材质、版本和源图；`docker compose down` 保留卷，`down -v` 会删除数据。常规 Python 环境运行 `pip install -r requirements.txt` 后 `./start.sh`；PORT 与 LOOMLAB_DATA_DIR 可更改地址及存储。Dockerfile基于本地已有solo12-scanweave:1.0依赖镜像，Python3.11与3.12依赖按requirements标记安装。

## 实际功能

1. 经/纬两色与组织结构生成织纹底色和相对高度，含平纹、斜纹、方平组织。
2. 导入PNG/JPEG照片作为底色源图；EXIF朝向归一、透明像素在线性色彩空间与暗底合成。
3. 源图周期坐标的缩放、平移与旋转，以最近邻采样保持原像素。
4. 相对高度从线性亮度生成，设置高低点、反转和周期平滑。
5. 高度派生单位切线法线，可选Y向上或向下约定。
6. 高度局部细节调制基础粗糙度。
7. 周期邻域高度生成近似环境遮蔽AO。
8. 平面光照预览，可改变光源方位与仰角；线性照明后转sRGB显示。
9. 底色、高度、法线、粗糙、AO分别预览和下载。
10. 3×3重复预览检查材质拼接。
11. 任一通道的边界平均/峰值误差及灰度直方图诊断。
12. ORM打包：R=AO、G=粗糙度、B=非金属0；PNG数据通道不作sRGB变换。
13. 可选磨损处理：高处、凸转折与过渡坡面优先磨白，低洼处保留；覆盖程度、斑块大小、随机种子可调，磨损强度可为0以单独预览遮罩。
14. 磨损区同步改变底色（褪色纤维色）、高度（削低凸起并加入细纤维起伏）与粗糙度；法线与AO按磨损后的最终高度重新计算。
15. 磨损遮罩单列为通道，可预览、诊断和单独下载。
16. 磨损参数与种子随材质、版本、工程保存，结果可重现；关闭磨损或强度置0即回到原材质。
17. 导出贴图ZIP与色彩空间/法线约定清单。
18. 命名材质版本，恢复当时参数与不可变源图。
19. 下载/导入可编辑工程，保留版本所引用的各张源图。
20. /prepare源图准备工具可对齐、融合、校色、遮罩、接片并导出；它是独立输入准备步骤。

操作：首页创建合成示范，切换各贴图，改变组织/高度/光照后应用，留存版本，再下载贴图和工程。导入自有照片后选择照片模式。示范完全为程序合成，不冒充摄影实测。

## 数值语义和限制

源图不超过4096²；材质输出32至1024²，每次在CPU同步计算，不承诺未测大规模吞吐。高度是归一化相对量，没有测量毫米尺度。AO和高光都是近似，不是物理渲染器。织纹重复数需用户按组织周期选择，首尾不兼容时诊断会显示接缝；程序不会自动修接缝。边界像素差是诊断量，连续采样首尾像素无需完全相等。

正常API以 `/loom/materials` 管理材质，修改请求携带当前revision防止旧页面覆盖；图片`/loom/materials/{id}/map/{channel}.png`，诊断`/inspect/{channel}`，下载`/export.zip`与`/project.zip`，工程导入`POST /loom/import`。原始图片内容寻址并保留，版本恢复不会改写旧图。磨损遮罩尺寸与材质一致、灰度线性，白为磨损、黑为保留，可经`/map/wear.png`预览、`/map/wear.png/download`单独下载；遮罩与结果由尺寸、参数和种子确定，同一参数重复渲染结果一致。
